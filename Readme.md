<h1 align="center">FaceCluster</h1>

<p align="center">
  A Python computer vision project for detecting and clustering similar faces across multiple images using <b>InsightFace</b>.
</p>

<h2>Features</h2>

<ul>
  <li><b>Face Detection</b> — Detect faces using InsightFace</li>
  <li><b>Face Clustering</b> — Group similar faces using face embeddings</li>
  <li><b>Image Visualization</b> — View detected and clustered faces</li>
  <li><b>Configurable</b> — Adjust similarity thresholds and canvas settings</li>
</ul>

<h2>Usage</h2>

<p>Place your images inside the <code>media/</code> directory and run:</p>

<pre><code>python main.py</code></pre>

<p>Configuration can be adjusted in <code>config.py</code>.</p>
